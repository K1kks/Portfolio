# Kikks — Frontend Portfolio

A responsive portfolio by Mikael (Kikks) Cuyugan, a 2026 BSIT graduate focusing on junior frontend development. Built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in your browser. For the best local workflow, open the folder in VS Code and run the Live Server extension.

## What's included

- `index.html`, `styles.css`, `script.js` — portfolio homepage and project filters.
- `dental-demo/` — interactive MolarCare dental clinic frontend prototype.
- `assets/` — original vector previews, favicon, and the downloadable resume PDF.
- `GITHUB_PROFILE_README.md` — suggested GitHub profile README content.

## Projects shown

- **MolarCare:** independent frontend learning prototype. Data is demo-only and saved locally in the current browser; no real patient information, live SMS, or secure authentication.
- **CIT-U MarketMatch:** university team project. Contribution description is based on the provided commit-history screenshot: cart pricing/totals, cart navigation, cart scrolling, and UI fixes.
- **EventEase:** team capstone project. Contribution focuses on assigned booking and event pages implemented with AI assistance from teammate-provided Figma references.

## Publish to the current GitHub Pages site

Your current live URL is `https://k1kks.github.io/Kikks.github.io/`.

1. Download this package and extract it.
2. Open your existing GitHub repository for `Kikks.github.io`.
3. Upload the **contents** of this folder to the repository root, replacing the old `index.html`, CSS, JavaScript, and assets. Keep `dental-demo/` as a subfolder.
4. Commit the changes to the branch configured in **Settings → Pages** (usually `main`).
5. After GitHub Pages redeploys, check the portfolio and open `https://k1kks.github.io/Kikks.github.io/dental-demo/`.

Before sharing the MolarCare demo, remember that it is a browser-only prototype and not a real clinic system. Don't use real patient records or personal health information.
